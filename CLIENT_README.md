# 🚀 ToDoLite - Профессиональный Задачник

## 📋 Описание

ToDoLite - это современное веб-приложение для управления задачами с поддержкой Markdown, автоматическим резервным копированием и системой уведомлений.

## ✨ Основные возможности

- **📝 Управление задачами** - создание, редактирование, отслеживание статуса
- **🎨 Markdown редактор** - богатое форматирование описаний и комментариев
- **📊 Два режима просмотра** - Kanban (Agile) и Eisenhower Matrix
- **🔄 Автоматическое резервное копирование** - защита ваших данных
- **🔄 Автоматическая миграция задач** - автоматическое перемещение задач между категориями на основе дат
- **📤 Экспорт/Импорт** - работа с данными в различных форматах
- **🔔 Система уведомлений** - напоминания о задачах
- **🌙 Темная тема** - комфортная работа в любое время

## 🛠️ Системные требования

- **Windows 10/11** (64-bit)
- **Python 3.8+** (автоматически устанавливается)
- **4 ГБ RAM** (минимум)
- **100 МБ** свободного места на диске

## 🚀 Быстрая установка

### Вариант 1: Автоматическая установка (Рекомендуется)

1. **Скачайте** архив **`ToDoLite_v1.5.5.zip`** (или актуальный из поставки). В архиве файлы лежат **в корне** (без вложенной папки), вместе с `README.md`, `LICENSE` и `convert_line_endings.*`.
2. **Распакуйте** в любую папку (например, `C:\ToDoLite\`)
3. **Запустите** `install.bat` от имени администратора
4. **Дождитесь** завершения установки
5. **Запустите** `start.bat`

### Вариант 2: Ручная установка

1. **Установите Python** с [python.org](https://python.org) (версия 3.8+)
2. **Распакуйте** архив в папку
3. **Откройте** командную строку в папке с программой
4. **Выполните** команды:
   ```cmd
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python tray_app.py
   ```

## 🎯 Первый запуск

1. **Запустите** `start.bat`
2. **Дождитесь** появления иконки в системном трее
3. **Откройте** браузер и перейдите на `http://localhost:5000`
4. **Создайте** первую задачу

- **"Создать резервную копию"** - ручное резервное копирование
- **"Экспорт задач"** - экспорт в файл
- **"Импорт задач"** - импорт из файла

### Через веб-интерфейс:
- **Создание задач** - форма в верхней части
- **Редактирование** - кнопка "Редактировать" на карточке задачи
- **Изменение статуса** - перетаскивание в Kanban режиме
- **Добавление комментариев** - Markdown редактор
- **🔄 Обновить категории** - кнопка для ручного обновления категорий задач по датам

## 📝 Markdown редактор

ToDoLite поддерживает полный синтаксис Markdown:

### Основные элементы:
- **Заголовки**: `# Заголовок 1`, `## Заголовок 2`
- **Жирный текст**: `**жирный**`
- **Курсив**: `*курсив*`
- **Списки**: `- элемент` или `1. элемент`
- **Цитаты**: `> цитата`
- **Ссылки**: `[текст](https://example.com)`
- **Код**: `` `код` `` или блоки кода
- **Таблицы**: стандартный синтаксис Markdown

### Панель инструментов:
- **B** - жирный текст
- **I** - курсив
- **C** - код
- **H2** - заголовок
- **•** - список
- **1.** - нумерованный список
- **"** - цитата
- **🔗** - ссылка
- **—** - разделитель
- **👁** - предпросмотр

## 🔄 Автоматическая миграция задач

ToDoLite автоматически перемещает задачи между категориями на основе дат выполнения или отложенности:

### Как это работает:
1. **Установите дату** выполнения (`due_date`) или отложенности (`scheduled_date`) для задачи
2. **Система автоматически** переместит задачу в соответствующую категорию:
   - **🔥 Сегодня** - если дата сегодня или просрочена
   - **📅 Завтра** - если дата завтра
   - **📆 На неделе** - если дата в текущей неделе (если сегодня пятница, то + понедельник)
   - **🔮 Далекие** - если дата дальше чем вторник следующей недели

### Автоматическая проверка:
- Проверка выполняется **каждые 30 минут** автоматически
- Можно запустить вручную кнопкой **"🔄 Обновить"** в верхней панели

### Защищённые категории:
- Задачи в **"👁️ Отслеживаем"** не перемещаются автоматически (кроме просроченных)
- Задачи в **"🔥 Сегодня"** не перемещаются автоматически (кроме просроченных)
- Просроченные задачи всегда перемещаются в **"🔥 Сегодня"**

### Настройка:
В файле `config.json` можно настроить:
```json
{
  "auto_migration": {
    "enabled": true,
    "interval_minutes": 30
  }
}
```
- `enabled` - включить/выключить автоматическую миграцию
- `interval_minutes` - интервал проверки в минутах

## ⚙️ Настройки

### Конфигурация (`config.json`):
```json
{
  "backup": {
    "enabled": true,
    "interval_hours": 1,
    "primary_paths": ["C:\\Backups\\ToDoLite"],
    "fallback_path": "C:\\Users\\%USERNAME%\\Documents\\ToDoLite_Backups",
    "max_backups": 10,
    "compress": true
  }
}
```

### Настройка резервного копирования:
- **enabled** - включить/выключить автоматическое резервное копирование
- **interval_hours** - интервал между копиями (часы)
- **primary_paths** - основные пути для резервных копий
- **fallback_path** - резервный путь
- **max_backups** - максимальное количество копий
- **compress** - сжатие резервных копий

## 📊 Режимы просмотра

### Kanban (Agile):
- **Новые** - только что созданные задачи
- **Позже** - отложенные задачи
- **Отслеживание** - задачи под наблюдением
- **В работе** - активные задачи
- **Ожидание** - задачи, ожидающие внешних действий
- **Размышление** - задачи, требующие анализа
- **Готово** - завершенные задачи
- **Отменено** - отмененные задачи

### Eisenhower Matrix:
- **Срочно и важно** - критические задачи
- **Срочно, но не важно** - делегируемые задачи
- **Не срочно, но важно** - планируемые задачи
- **Не срочно и не важно** - откладываемые задачи

## 🔧 Устранение неполадок

### Проблема: Не запускается
**Решение:**
1. Проверьте, установлен ли Python
2. Запустите `install.bat` от имени администратора
3. Проверьте логи в консоли

### Проблема: Не открывается в браузере
**Решение:**
1. Убедитесь, что порт 5000 свободен
2. Попробуйте `http://127.0.0.1:5000`
3. Проверьте настройки брандмауэра

### Проблема: Не работает резервное копирование
**Решение:**
1. Проверьте права доступа к папкам резервного копирования
2. Убедитесь, что папки существуют
3. Проверьте настройки в `config.json`

### Проблема: Не отображается иконка в трее
**Решение:**
1. Перезапустите программу
2. Проверьте, не скрыта ли иконка в настройках Windows
3. Для отладки запустите из командной строки с активированным venv: `python tray_app.py`

## 📞 Поддержка

### Логи и диагностика:
- **Консоль** - `start_with_console.bat`
- **Логи** - папка `%TEMP%\ToDoLite\`
- **База данных** - файл `tasks.db`

### Полезные команды:
```cmd
# Прослушивание порта 5000 (только LISTENING)
netstat -ano | findstr "LISTENING" | findstr ":5000 "

# Остановка процессов Python (осторожно: закроет все python.exe / pythonw.exe)
# Или запустите kill_python_processes.cmd из папки программы
taskkill /F /IM pythonw.exe
taskkill /F /IM python.exe

# Запуск: start.bat или run_tray_silent.bat из папки программы
```
