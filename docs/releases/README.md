# Релизы ToDoLite

Документация и заметки по версиям. Готовые **клиентские** архивы (без venv) при сборке именуются `ToDoLite_v*.*.*.zip`; актуальный пример — **v1.5.5**.

## Текущий клиентский пакет

### [v1.5.5](v1.5.5/)

- Архив с **плоским корнем** (файлы сразу в корне ZIP).
- Состав: код, `README.md`, `CLIENT_README.md`, `LICENSE`, скрипты установки/запуска, `convert_line_endings.*`, `VERSION.txt`.
- Подробности: [RELEASE_NOTES_v1.5.5.md](v1.5.5/RELEASE_NOTES_v1.5.5.md)

## Структура папки релиза

- `RELEASE_NOTES_v*.md` — описание (русский)
- `GITHUB_RELEASE_v*.md` — черновик текста для GitHub Releases (английский)
- `RELEASE_TAGS_v*.txt` — имя тега и файла архива
- при наличии сборки: `ToDoLite_v*.zip`

## Установка из архива

1. Распаковать.
2. `install.bat` от имени администратора.
3. `start.bat` или `run_tray_silent.bat`.
4. Браузер: http://localhost:5000
