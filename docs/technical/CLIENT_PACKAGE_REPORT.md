## 🚀 Процесс развертывания

### Для клиентов:
1. **Получение пакета** - архив `ToDoLite-Client-v1.4-20251013.zip`
2. **Распаковка** - в любую папку (например, `C:\ToDoLite\`)
3. **Установка** - запуск `install.bat` от имени администратора
4. **Запуск** - запуск `start.bat` или ярлыка на рабочем столе
5. **Использование** - открытие `http://localhost:5000` в браузере

### Автоматические действия при установке:
- ✅ Проверка наличия Python 3.8+
- ✅ Обновление pip
- ✅ Установка зависимостей из requirements.txt
- ✅ Создание папок для резервного копирования
- ✅ Создание ярлыка на рабочем столе
- ✅ Проверка конфигурации
- ✅ Финальная проверка всех модулей

## 📋 Системные требования

### Минимальные требования:
- **ОС**: Windows 10/11 (64-bit)
- **Python**: 3.8+ (автоматически проверяется)
- **RAM**: 4 ГБ (минимум)
- **Диск**: 100 МБ свободного места
