## Запуск (напоминание)

После клонирования: виртуальное окружение, `pip install -r requirements.txt`, затем `python tray_app.py` или `run_tray_silent.bat` из корня проекта. В **клиентском архиве** дополнительно есть `install.bat` и `start.bat`.
